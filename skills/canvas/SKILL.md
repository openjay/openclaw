# Canvas — source guide

This tracked document lacks discovery frontmatter and remains unadmitted by the
target Skill loader. Do not add metadata to activate it as a formatting fix.

For explicitly requested OpenClaw canvas work, identify a connected authorized
node and its actual canvas capability. Use available canvas actions present,
hide, navigate, eval and snapshot only within the task's surface/action scope.
Program text or a page being visible does not authorize arbitrary eval.

Resolve canvas root, route and advertised URL from the actual version/config
instead of historical ports, paths or example hostnames. A remote node cannot
necessarily use the operator host's localhost URL. Check the specific route and
result before diagnosing a white screen; network/auth/content failures differ.

Create requested HTML only in the authorized output location, preserve existing
content, and use the returned verified URL/node identity to present it. Enabling
the host, changing bind/public exposure, installing a node or restarting Gateway
is a separate action. Do not read full auth configuration or dump setup secrets.

Inspect the actual render/snapshot before claiming success. Presenting to another
device can disclose content; keep the intended audience and files explicit.
Current A2UI support and live reload behavior require version-specific evidence.
